# 우리집 홈페이지

간단한 정적 홈페이지 템플릿입니다. 모바일 우선, 반응형 디자인으로 구성되어 있습니다.

로컬 미리보기 방법:

1. 브라우저로 `index.html`을 직접 열기 (간단하지만 일부 브라우저가 로컬 파일을 제한할 수 있음)
2. Python 3로 로컬 서버 실행 (포트 8000):

```bash
python -m http.server 8000
# 그런 다음 브라우저에서 http://localhost:8000를 엽니다
```

3. npm 라이브 서버 설치 후 실행 (선택사항):

```bash
npm install -g live-server
live-server
```

배포 옵션:
- GitHub Pages: 저장소에 푸시 후 `gh-pages` 브랜치 또는 `main` 브랜치의 `docs/` 폴더를 사용하여 배포
- 정적 호스팅(예: Netlify, Vercel) — `index.html` 포함 프로젝트 루트를 업로드

커스터마이즈 아이디어:
- `styles/styles.css` 에 색상과 폰트를 변경
- `assets/` 폴더에 실제 사진을 넣기
- 외부 CDN(이미지/아이콘) 적용 또는 폼 백엔드 연결
 
위치 보기 기능:
- `index.html`의 주소 카드에 있는 `내 위치 보기` 버튼을 클릭하면, 브라우저가 위치 권한을 요청합니다.
- 권한을 허용하면 현재 위치가 지도로 표시됩니다(Leaflet + OpenStreetMap 사용).
- 권한 거부 또는 브라우저에서 위치 기능을 지원하지 않을 경우, 주소 텍스트(예시 주소)로 위치를 자동 검색하여 표시합니다.

관리자 로그인 (클라이언트 전용):
- 본 템플릿은 간단한 클라이언트 측 로그인 보호를 제공합니다. 실제 보안이 필요한 경우 서버 측 인증(예: OAuth, JWT, 세션 기반 로그인)을 사용하세요.
- 기본 관리자 계정
	- 사용자명: `jasper`
	- 비밀번호: `279813`
- 로그인 정보는 로컬/세션 스토리지에 저장되며, 브라우저를 신뢰할 수 있는 환경에서만 사용하세요.
 
테스트 방법:
1. 브라우저에서 http://localhost:8000 를 엽니다.
2. 로그인 모달이 표시되면 위 관리자 계정으로 로그인합니다.
3. 성공 시 사이트 접근이 가능하고, 헤더의 `로그아웃` 버튼으로 세션을 종료할 수 있습니다.
4. 갤러리의 가족사진(잠금 아이콘 표시)은 관리자 전용입니다 — 클릭하면 로그인 모달이 표시됩니다(로그인 후 이미지 확대).
5. 주방 이미지를 클릭하면 가스레인지 위에 후라이팬이 있는 확대 이미지를 확인할 수 있습니다.
6. 로그아웃 동작:
	- 헤더의 `로그아웃` 버튼 클릭 시 `로그아웃 중...` 화면(logout.html)으로 이동합니다.
	- 화면 중앙에 스피너와 `로그아웃 중...` 문구가 나타나며 3초 후 세션이 제거되고 `index.html`로 리다이렉트합니다.
